# Source adjudication

Use this skill when retrieved Everstake sources disagree.

1. Separate publication date from the date a claim describes.
2. Prefer current Tier 1 canonical company pages for mutable facts.
3. Use dated historical pages as snapshots, not current truth.
4. Collapse duplicate syndication groups before comparing support.
5. If equally authoritative current sources conflict, answer that no reliable value was found and cite neither as settled truth.
