## How to read the scores

Each answer in the new main run receives a score from 0 to 100%: factual correctness contributes up to 40 points, completeness up to 30, source grounding up to 20, and handling uncertainty up to 10. These are rubric scores assigned by a coding assistant, not probabilities of correctness or independently verified accuracy.

We separately retain a pass/fail verdict: whether the question was fully answered. An answer can therefore receive **85% and still fail**. A correct abstention can receive 100%; a technical error without an answer receives 0%. Historical runs are not automatically assigned percentage scores.

Examples: CEO — **85%**, network count — **80%**, company history — **70%**, SWQOS bill — **40%**. The first has the correct name but problems with the title; the last contains an actual error relating two amounts.
