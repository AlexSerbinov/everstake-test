# Updates

Start with `controller.ts`: it persists source jobs, deduplicates requests and executes one source at a time under a renewable SQLite lease. `settings.ts` stores operator-selected enablement, intervals and priorities without changing source authority. `discover-videos.ts` checks the configured official channel and bounded searches using metadata-only yt-dlp calls. `refresh-videos.ts` skips the existing inventory and stored video IDs before downloading or transcribing anything, then caches each new video's processing independently of corpus activation. Soniox jobs and Gemini attempts use the existing ledger; ambiguous submissions retain their provider state. The application sends accepted additions through the same staged index and embedding cache as web refreshes. Tests cover scheduling, restart, duplicate requests, authorization, old-video skipping and failure preservation. See [the operating contract](../../../docs/UPDATES.md) for deployment and scope limits.
