# Saved cost measurements

Exported API usage and cost records live here, including a separate [YouTube breakdown](YouTube/README.md). These files make spending traceable without needing access to the running database.

Read [COST.md](../../COST.md) for totals and calculation rules. Known usage costs, unknown spending, and future forecasts are different categories.

## Open a record

- [Measured ledger](measured-ledger.json): the saved rebuild cost snapshot, with generation time, scope, totals and underlying records.
- [YouTube records](YouTube/README.md): transcription batches and speaker-review costs, including later updates.

Do not add all files together: exports can contain overlapping calls. The root cost report explains which snapshot each total uses; opening this folder makes no API calls.
