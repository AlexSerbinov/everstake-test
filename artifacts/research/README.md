# Source survey evidence

Saved research notes document the source survey used to understand the available material before collection. They support decisions about coverage and source selection.

For current collection rules and results, read [CORPUS.md](../../docs/CORPUS.md). These exploratory notes are not a replacement for the collected corpus.

Open [source-survey.md](source-survey.md) for the saved survey. Broader design discussions live in [docs/research](../../docs/research/README.md); the current source catalogue lives in [assistant/config/sources.yaml](../../assistant/config/sources.yaml). Neither research folder is automatically imported into search.
