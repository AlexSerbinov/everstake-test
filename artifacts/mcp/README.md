# MCP comparison evidence

Captured responses, supporting evidence, grades, and measurements document the comparison with Everstake’s MCP server. Keeping the raw records makes the written comparison auditable.

See [EVAL.md](../../EVAL.md) for the comparison and its limitations. These files are saved experiment outputs, not the application’s knowledge source.

## Follow the comparison

1. [Captured MCP responses](capture-2026-09-13.json) and [prepared evidence](evidence-2026-09-13.json) show the saved material available to the comparison.
2. [Core-v2 answers](../evaluation/mcp-core-v2.json) show what the model answered on that question set.
3. [Core-v2 measurements](core-v2-measurements.json) preserve its run and usage records.
4. [Written comparison](../../docs/MCP_COMPARISON.md) explains the method and its limits.

[Earlier grades](grades-2026-09-13.json) and [earlier measurements](measurements-2026-09-13.json) remain separate historical records. They are not extra results to add to the core-v2 score.

The linked comparison document contains both the agent summary and a separate MCP result. The agent headline is not the MCP score; use the labelled run and question set when comparing them.
