# Evaluation review records

Saved grading records explain how evaluation answers were judged. Interim and final reviews are kept for traceability, so the newest-looking filename alone is not the reported result.

Start with [EVAL.md](../../EVAL.md), then follow its evidence links to the relevant run and grade.

- [Interim review](2026-09-13-interim.json): the earlier grading snapshot.
- [Final review](2026-09-13-final.json): the subsequent review for a later run pair, not a universal final grade for every later run.

The fixed questions are in [eval/](../../eval/README.md), answers are in [artifacts/evaluation/](../../artifacts/evaluation/README.md), and diagnostic explanations are in [docs/evaluation/](../evaluation/README.md). Match the run named in a review to the answer it grades.

The files grade different run pairs: interim covers `agent-b0993aac` / `baseline-5c467370`; final covers `agent-9a157413` / `baseline-c656c369`. They are not two verdicts on the same recorded answers. Match each grade row to its `runId` before comparing.
