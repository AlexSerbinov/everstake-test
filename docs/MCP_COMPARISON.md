**Результат: 6/20, без виявлених непідтверджених фактів, $0.236955.** П’ять успіхів — правильні відмови на негативні питання; один — фактична відповідь про сертифікації.

Для дослідницьких питань наш корпус ширший: у ньому є статті, історія та суперечливі фрагменти. MCP пропонує прямі операційні інструменти, зокрема параметри мереж і калькулятор. Він не потребує нашого збору й індексації; наш агент дорожчий та може помилятися при зіставленні джерел.

## Як перевіряли

- Ті самі тексти 20 питань `core-v2`, та сама модель Gemini 3.8 Flash.
- Лише зафіксовані відповіді інструментів офіційного MCP; наш корпус та еталони не передавалися моделі.
- Дані MCP зібрано через stdio 13 вересня 2026 року з версії `68f5f5f`. Запити операційних даних зверталися до dashboard API.
- Модель отримала загальний набір відповідей інструментів і одну спробу відповісти. Сценарний пробний розрахунок не передавався як загальний факт. Інтеграційних заявок не надсилали.
- Автономний вибір MCP-інструментів, їхню затримку та загальну перевагу в актуальності не перевіряли.
- Після прогону coding assistant зіставив відповіді з еталонами й збереженими джерелами. Це не сліпе оцінювання й не висновок незалежної людини.
