# Historical project material

Earlier plans, prototype reports, and superseded drafts are retained here to make the development history understandable. Their measurements and design choices belong to the versions they describe.

For the delivered implementation, start with the [root README](../../README.md) and [REPORT.md](../../REPORT.md).
