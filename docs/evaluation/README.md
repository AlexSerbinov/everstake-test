# Evaluation investigations

Saved notes and runtime records explain changes to question sets, review rules, and diagnostic checks. Historical results retain their original scope.

Start with [EVAL.md](../../EVAL.md) for the current published results, or [general-quality](general-quality/README.md) for the saved answer-quality investigation.

## Follow one result

The [question files](../../eval/README.md) define what to ask. The [saved runs](../../artifacts/evaluation/README.md) record the answers. This folder explains investigations into those answers; it does not provide another question runner.

[General-quality investigation](general-quality/README.md) retains the previous report, runtime snapshots and diagnostic costs together. Its historical test counts and commands describe that investigation, not a new verification of today's checkout.
